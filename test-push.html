Android 不通过 sound / badge 直接指定系统通知声音或角标。

加密使用 JSON / 表单 / 查询参数；目标保留在密文外。删除需填写消息 ID。target_count 是接受投递的设备数，不代表已经收到。

使用上方推送 ID 和目标；可修改示例测试不同平台的消息类型。当前服务端 CORS 不允许事件头，跨域测试请留空事件名称。

生成不会发送请求。只对测试设备操作；不要用现有手机客户端凭据注册不同公钥。生成的电脑设备可在连接页解密消息，手机公钥需由手机提供。

使用本机设备凭据连接 /ws?key=…。连接已有设备会替换它的在线连接，推荐生成并注册独立测试设备。收到消息只展示在日志中，不自动 ACK；ACK 会从服务端移除待投递消息。

自动回复应用层 ping；只有当前页生成的电脑 RSA 私钥可解密 RSA 消息。发送端密文使用推送页的 AES 密钥。页面不保存消息历史，关闭后日志丢失。

仅 Go 服务端支持。后台用 Cookie 登录，请通过反向代理把此测试页放在后台同源地址下打开（协议、主机、端口相同）；本地文件直接打开无法测试后台。这里不会放宽服务端认证或跨域规则。
